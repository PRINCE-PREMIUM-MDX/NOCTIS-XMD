✦ Comment faire le pairing ✦

Ouvrez WhatsApp sur le téléphone que vous voulez connecter.

Allez dans Paramètres → Appareils liés → Lier un appareil.

Choisissez « Lier avec le numéro de téléphone » puis entrez votre numéro ci-dessus.

Cliquez sur Obtenir mon code, puis saisissez le code affiché dans WhatsApp.

Patientez quelques secondes, votre session NOCTIS XMD est connectée !

✦ Règles importantes ✦

  • Ne partagez jamais votre code ou votre session avec une autre personne.
  • Utilisez un numéro que vous possédez réellement, pas un numéro tiers.
  • Toute utilisation abusive (spam, harcèlement) entraîne un bannissement immédiat.
  • Le service est fourni « tel quel », sans garantie de disponibilité continue.
  • En cas de déconnexion, refaites simplement le pairing pour reconnecter votre session.
